ANALISIS DE SENSIBILIDAD (sobre el caso base)
==============================================================================
Se varia el peso de un criterio de 0 a 1 y los demas se ajustan en proporcion:
  w_j(t) = w_j * (1 - t) / (1 - w_k)
Cada puntaje es una recta: S_i(t) = b_i + (a_i - b_i) * t,  con a_i = r_ik  y  b_i = suma(w_j * r_ij, j != k) / (1 - w_k)
  Throughput (peso base 0.1882): el ganador no cambia para ningun peso
